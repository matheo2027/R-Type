Detailed Description

Manages all systems in the ECS (Entity-Component-System) architecture.

This file defines the SystemManager class, which is responsible for updating and managing different systems used in the game. It holds a collection of systems that implement the ISystem interface.

Note
Systems are used to handle specific game functionalities such as movement, rendering, player interactions, enemy behavior, bullet management, and box handling.
