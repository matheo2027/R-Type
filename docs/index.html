R-Type

R-Type is a 2D side-scrolling shoot-em-up game developed by Irem in 1987. The game is set in a futuristic world where the player controls a space fighter ship called the R-9a "Arrowhead" to fight against the Bydo Empire. The game is known for its difficulty and unique power-up system.

This project is a re-implementation of the original game using modern C++ and the SFML library. The goal of this project is to learn more about game development and to improve our programming skills.

For more information about the original game, visit the Wikipedia page.

Features

The game will feature the following:

  • 2D side-scrolling gameplay
  • Multiple levels with unique enemies and bosses
  • Power-up system
  • Local multiplayer
  • Sound and music

Dependencies

The project uses the following libraries:

  • SFML - Simple and Fast Multimedia Library
