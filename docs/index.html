Welcome to the R-Type Project Documentation

R-Type is a shoot 'em up video game project developed to implement advanced programming concepts and explore game architecture using C++ and the SFML library.

Project Objective

The main objective of R-Type is to provide an engaging gaming experience with dynamic level design and smooth gameplay. The game emphasizes retro style while integrating modern features, allowing players to immerse themselves in an adventurous journey.

Technologies Used

  • C++: The primary programming language used for game development.
  • SFML: The library used for handling graphics rendering, user input, and sound.
  • Entity-Component-System (ECS): The architecture used to manage entities and their components within the game.

Main Features

  • Scene management with interactive elements.
  • An infinitely scrolling background for an immersive gaming experience.
  • Keyboard input support for smooth control of the spaceship.
  • Integration of multiple levels with varied enemies.

Installation and Execution

To run the project, clone the repository from GitHub, ensure SFML is installed, and compile the project using the appropriate commands. Please refer to the "Installation" section for more details.
